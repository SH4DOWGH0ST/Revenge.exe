#

Revenge.exe is an video game about how you got an unknown virus on your computer called "Revenge.exe". You must research about the virus, its history and creator: N3verF0rg3t. The only app you have access to is google chrome. Delete the virus, before its too late...

> [!CAUTION]
> Despite being about viruses, hacking, and ransomware, this game does not teach or encourage any illegal content whatover.

> This was coded and deployed on GitHub by Google AI studio

> All storyboarding/lore was created completely without the use of AI.

#

### The Virus ⚠️

The virus is called Revenge.exe and has a command terminal. The virus follows commands created by it's owner in case of an catastrophic problem. The virus is a new, highly dangerous computer virus created in 2026.

#

### Chrome/Google 🌐

Use the google search engine (not actually google BTW) to research the virus and find an possible way to stop, while uncovering the lore of the creator.

#

### Copilot 📕

Use Copilot to get a basic tutorial or how to play the game or what start looking up on chrome (google).

#

### Achievements 🎖️

Get achievements by running certain commands, using certain apps, or googling certain things.
